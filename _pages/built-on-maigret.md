[Maigret](https://github.com/soxoj/maigret) is MIT-licensed, so anyone can wrap it into whatever they need. Here is what people did with it.

## Hosted services

- [Maigret Telegram bot](https://maigret.app) - the community bot: send a username, get the report back, nothing to install
- [Maigret on Apify](https://apify.com/khadinakbar/maigret-username-osint) - runs a search in the cloud and hands back JSON or CSV, with [a second implementation](https://apify.com/ntriqpro/maigret-actor) next to it

## Integrations

- [mcp-maigret](https://github.com/BurtTheCoder/mcp-maigret) - an MCP server, so an AI assistant can run Maigret on its own

## Or run your own

The [web interface](https://github.com/soxoj/maigret#web-interface) ships inside the `soxoj/maigret:web` Docker image and comes up as a hosted app in one click.

Built something on Maigret? [Tell me](https://t.me/soxoj) and it goes on this list.
